# Published pages

Static pages published automatically by [EVA](https://github.com/abdigani67/eva-organism),
served at <https://abdigani67.github.io/>.

Content lives in `docs/`, which is what GitHub Pages serves. Each offer gets its own
folder, written when EVA decides to test that offer and not before.

## What you will and will not find here

Pages here describe services being offered for the first time. They carry no
testimonials, no customer counts and no urgency devices, because there are no
customers to count when a page goes up and inventing them would be a lie told to
the people the page exists to learn from.

Nothing here tracks the reader. No analytics, no pixels, no third-party scripts —
every page is self-contained HTML with inline styles.

## Why this repository is separate from EVA's source

The token that publishes here has write access to this repository. Keeping it apart
from `eva-organism` means that token can add a page and nothing else; pointed at
the source repository it could rewrite EVA's own code.
